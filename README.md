## 📌 Sobre el Proyecto
Solución web para clínicas y hospitales que facilita la administración de servicios básicos y la presentación de información institucional.
### Funcionalidades
*   Catálogo de servicios médicos.
*   Información de contacto y horarios.
*   Diseño limpio y profesional.
